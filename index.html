THE IDEA

A pass transfers influence.

If Player A passes to B, part of A's current rank flows to B. A player receiving rank from several important players becomes more influential in the network.

CORE FORMULA
PR(p) = 0.15/N + 0.85 × Σ PR(q)/L(q)

15% baseline keeps the network connected. 85% follows the links.

02
IMPORTANT

Influence ≠ "best player".

PageRank is a network metric. Goals, tackles, speed and other football skills are different measurements.

HOW TO PLAY

Read the match like a data analyst.

  1. Watch the passes. The glowing network shows who feeds whom.
  2. Run a round. New PageRank values are calculated from the current network.
  3. Find the influencer. The largest ring and highest bar identify the current network leader.
